# Competitive Programming

Solutions from my competitive programming practice, mostly written during the A2SV (Africa to Silicon Valley) fellowship. Over that time I solved 600+ problems on LeetCode and Codeforces.

Most solutions are in Python, with a few in Java and C++.

## How the repo is organised

- `NNNN-problem-name/`: LeetCode problems synced with [LeetHub](https://github.com/QasimWani/LeetHub). Each folder has the solution and the problem statement (`README.md`), and some have notes.
- `*.py` at the root: earlier LeetCode solutions, one file per problem.
- `Progress Sheet/`: problems from the A2SV progress sheet.
- `camp-II/`, `afterCamp/`: problems from A2SV camp and after it.
- `technicalPrep/`: interview preparation.
- Named folders such as `Ehab Is an Odd Person/` and `C - Alternating Subsequence/`: Codeforces problems. Folders ending in `- GFG` are GeeksforGeeks problems.
